# 红迹・数忆（红色网页设计大赛作品）

一个可点击、可跳转的多页面红色主题网站，采用深红 + 鎏金的国风视觉。全站图片均为本地文件，双击即可打开，无需联网。

## 一、功能一览

- **首页（一卷山河）**：长卷式叙事——卷首「红迹・数忆」→ 序「一百零五年」→ 五章目录 → 峥嵘岁月 / 时代群像 / 跨越时空 / 情景重现 / 红色经典 → 尾声
  - **卷首**：红旗油画背景、卷首语卡片与鎏金小碑，滚动时背景视差下沉；五个统计数字 105 / 10 / 16 / 4 / 5 一字排开
  - **五章目录**：编号 + 竖排章名 + 馆藏缩略图，一屏纵览五种证据
  - **实物图版**：馆藏铁索链、事件照片、十六张面孔、五本书脊，配档案编号与图版说明
  - **尾声**：红旗冲锋油画上的「下一页，由你落笔」，五章集印与留言 / 问答入口
- **历史事件**：10 个大事记时间轴，点击展开「背景 / 经过 / 意义」详情
  - **沉浸模式**：一键自动逐条展开并滚动，配「长征路线」进度条（Esc 或按钮可随时退出）；进入即响起《国际歌》/《东方红》，可在进度条下切换曲目或静音
  - **红色足迹路线图**：SVG 路线串起上海—南昌—井冈山—瑞金—遵义—平型关—华北—南京—北京—鸭绿江十站，点击站点直达对应事件
  - **中国地图事件分布**：真实边界数据（含南海诸岛与十段线）绘制的简化中国地图，10 个事件发生地按时间连线标注，点击标记直达对应事件
- **历史人物**：16 位人物，支持搜索；**卡片 3D 翻转**——悬停翻面看名言，点击查看完整生平
- **历史对话**：AI 模拟 6 位历史人物对话，回复带**打字机逐字效果**，附**推荐问题**一键发送；记录自动保存在本机、可一键清除
- **历史重现**：4 幕历史场景沉浸式全屏，播放第一视角视频（缺视频时自动退回动态图 + 音效）
- **历史作品**：经典红色著作卡片，点击直达介绍页
- **红色问答（新页面）**：5 关 × 4 题知识闯关，答对 ≥3 题过关、解锁下一关；**星火值**累计并显示在全站印章面板
- **留言板**：昵称 + 留言，服务端存储（`data/messages.json`），离线时降级为本地存储
  - **心声弹幕**：留言以红色金边弹幕在页面飘过，提交后自己的留言立刻飘出
- **全站互动**：
  - **五章集印**：浏览每个篇章会盖下「事 / 人 / 话 / 现 / 作」印章（停留 8 秒或完成关键互动即盖），集齐解锁「全章通览 · 星火相传」成就徽章
  - **虚拟纪念馆 · 献花**：右下角悬浮按钮，点击向英烈献花并记录累计朵数

以上进度（印章 / 献花 / 星火值）均保存在浏览器 localStorage，刷新不丢失。

## 二、如何打开

**方式 A（纯静态浏览）**：直接双击根目录下的 **`index.html`**，即可浏览整个网站（无需服务器；AI 对话部分会显示为"演示模式"）。

**方式 B（开启 AI 历史人物对话）**：见下方「五、开启 AI 历史人物对话」。

> 提示：全站 30 张图片已全部本地化（`image/` 目录），无网络也能完整显示。

## 四、图片来源与版权

- 事件照片（event-01 ~ 10）、人物肖像（figure-*）、场景图（scene-*）均来自 **Wikimedia Commons（维基共享资源）**，为公有领域或自由许可的历史照片，详细清单见 `image/图片清单.txt`。
- 中国地图边界数据来自**阿里云 DataV GeoAtlas** 的全国边界 GeoJSON（公开地理数据），经脚本投影简化为 SVG（`tools/tools_convert_map.js`），完整包含南海诸岛与十段线。
- 《国际歌》管弦乐与《东方红》1963 年录音来自 Wikimedia Commons，均为**公有领域**音频，存放于 `audio/` 目录。
- 首页 / 内页背景图为历史画卷风格图片，经模糊 + 变暗 + Ken Burns 慢速缩放处理。
- 4 段第一视角视频为自制的情景重现素材，存放于 `video/` 目录。
- 站点 favicon 为自绘 SVG 图形。

## 五、开启 AI 历史人物对话（DeepSeek）

"历史对话"页面可选择李大钊、周恩来、方志敏、江姐、董存瑞、雷锋 6 位人物，由 AI 以第一人称扮演他们与你对话（支持打字机效果与推荐问题）。

### 步骤（只需一次配置）

1. **填写密钥**：打开根目录的 `config.json`，把 `apiKey` 改成你的 DeepSeek API Key（`sk-` 开头）：
   ```json
   {
     "apiKey": "sk-你的密钥",
     "baseURL": "https://api.deepseek.com",
     "model": "deepseek-chat",
     "port": 3000
   }
   ```
   > 也可以不改文件，直接在命令行设置环境变量 `DEEPSEEK_API_KEY`。
   > ⚠️ **参赛提交前请确认不要把含真实密钥的 `config.json` 打包上传**（可提交 `config.example.json` 示例）。

2. **启动服务**：在项目根目录打开命令行（终端），运行：
   ```bash
   node server.js
   ```
   看到 `已启动` 和 `http://localhost:3000` 即成功。

3. **打开网站**：浏览器访问 **http://localhost:3000**，进入「历史对话」页即可与先辈对话。

### 说明

- 密钥只保存在你本机的 `config.json`，不会写入网页、不会上传，浏览器通过本地服务中转，避免跨域拦截。
- 服务端 `server.js` 用 Node 原生模块实现，**无需 `npm install`**。
- 若没有启动服务，聊天界面会自动降级为「演示模式」回复（带打字机效果），网站其余功能不受影响。
- AI 生成内容仅用于学习与纪念，请以真实史料为准。

## 六、留言板与其它说明

- **留言板**：启动 `node server.js` 后，留言会保存到 `data/messages.json`（多人共享）；纯静态打开时降级为浏览器本地存储。留言内容会同时以弹幕形式在页面飘出。请勿把 `data/` 目录设为公开可访问，服务端已默认屏蔽。
- **更换端口**：若 3000 端口被占用，可用环境变量指定端口，例如 `PORT=3001 node server.js`，再访问 `http://localhost:3001`。
- **更换背景图 / 头像**：替换 `image/` 下同名文件即可；人物头像支持 `.jpg` 与 `.webp`（在 `js/renwu.js` 中通过 `ext` 字段指定）。
- **人物 / 题库数据**：人物信息在 `js/renwu.js`，问答题库在 `js/quiz.js`，人物对话角色在 `js/chat.js` 与 `personas.js`，均可直接增删修改。
- **进度存储**：印章 `red_stamps_v1`、献花 `red_flowers_v1`、问答 `red_quiz_v1`、对话记录 `redchat_*`、本地留言 `red_messages_local`，均存于浏览器 localStorage；「清除浏览器数据」会重置这些进度。
